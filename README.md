# Mohamed Outerbah — Portfolio

Source code for [mohamedouterbah.com](https://www.mohamedouterbah.com) — my personal portfolio site.

## Stack

- **Next.js** (App Router) + **TypeScript**
- **Tailwind CSS** + Radix UI (shadcn-style primitives)
- **Framer Motion** for animations
- Deployed on Vercel

## Run locally

```bash
cd portfolio-v1
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## CV

The downloadable CV PDF is generated from `Mohamed_Outerbah_CV.html`:

```bash
./build-cv.sh   # or: cd portfolio-v1 && npm run cv
```

It renders the HTML with a headless Chromium browser and writes the PDF to `portfolio-v1/public/cv/`.
