# Mohamed Outerbah — Portfolio

Source code for [mohamedouterbah.com](https://www.mohamedouterbah.com) — my personal portfolio site.

## Stack

- **Next.js** (App Router) + **TypeScript**
- **Tailwind CSS** + Radix UI (shadcn-style primitives)
- **Framer Motion** for animations
- Deployed on Vercel

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
