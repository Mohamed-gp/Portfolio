# ✈️ Mohamed Outerbah – Portfolio

Welcome to my portfolio repository — home to **two different experiences** of who I am as a developer.

---

## 🧩 Versions Overview

### ** – Professional Portfolio**
📁 `portfolio-v1/`

The classic, clean, and professional version of my portfolio.  
Built to present my **skills, projects, and experience** in a straightforward and recruiter-friendly way.

**Highlights:**
- Built with **Next.js + TypeScript + TailwindCSS**
- Responsive, fast, and SEO-optimized
- Ideal for clients, recruiters, and professional contacts

**Run locally:**
```bash
cd portfolio-v1
npm install
npm run dev
````

---

### **v2 – Experimental 3D Portfolio**

📁 `portfolio-v2/`



You fly a **B2 Spirit** or other fighter jets (like the F15 or F35) through a 3D world,
landing on islands that represent different sections of my portfolio (Projects, About, Contact, etc.).

**Highlights:**

* Built with **Next.js + React Three Fiber + Three.js + Framer Motion**
* Features **real 3D flight mechanics**, smooth animations, and multi-language support
* Each aircraft comes with its own personality and humor
  (“Ready to nuke some deadlines 💣”, “Stealth mode activated ⚡”)

**Run locally:**

```bash
cd v2
npm install
npm run dev
```
